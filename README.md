# McGill-ECSE-202
Assignments given by  Frank p. Ferrie

Assignment 1: creating a java applet that simulates Newton's Law of a ball dropping from a specified height and bouncing as soon as it hits the floor, while taking energy loss into account.

Assignment 2:recreated the simulation in assignment 1 but this time we simulate multiple balls dropping at once using Threads

Assignemnt 3:recreated the simulation in assignment 2 while also implementing a sorting algorithm that sorts all the balls from decreasing to increasing size using a binary tree.

Assignment 4: recreated the same simulation in assignment 1 and 2 while also implementing a user interface that can change the number of balls, the speed of the ball, the energy loss, the size of the ball and etc.

Assignment 5: Using C language,we recreate Assignment 1 wich was written in Java.

Assigment 6: Using C language,we created a student database while also being able to read textfiles with all the student informations on it- This program responds to a list of commands.
